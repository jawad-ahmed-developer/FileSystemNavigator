# FileSystemNavigator

## 📁 Project Overview

**FileSystemNavigator** is a Java-based console application that simulates a hierarchical file system. It allows users to manage files and folders using common file system operations through a simple, menu-driven interface.

---

## 🚀 Features

* Create and delete files and folders
* Copy, cut, and paste files or directories
* Forward and backward directory navigation
* Rename files and folders
* Search files or folders recursively
* Sort files and directories (asc/desc)
* Direct jump to a specified path

---

## 🛠️ Technologies Used

* Java (OOP, Collections)
* Tree-based directory structure
* ArrayList
* Console-based UI
