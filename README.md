My Java Programming Project: 📁 FileSystemNavigator

A Java-based console application that simulates a hierarchical file system, allowing users to manage files and folders using real-world file operations. This project demonstrates strong use of data structures, recursion, modular design, and error handling, all wrapped in a clean, menu-driven interface.

🔑 Key Features
Folder & File Creation – Create directories and files dynamically
Copy, Cut & Paste – Perform file and folder copy/cut operations across directories
Navigation System – Move forward into folders and backward to parent directories
Rename Operations – Rename files and folders with validation
Delete Operations – Safely delete files and directories
Search Functionality – Recursively search for files or folders from root
Sorting – Sort files and folders in ascending or descending order
Direct Jump – Instantly navigate to a specific path
Menu-Driven Interface – Simple and user-friendly console interaction

🛠️ Technologies Used
Java (OOP, Collections, Recursion)
ArrayList & Tree-based data structures
Command-line / Console Interface
IntelliJ IDEA 

📁 Classes Overview
Directory.java –
Core logic of the file system including directory structure, file/folder operations, navigation, search, sorting, and error handling
Main.java –
Menu-driven user interface and helper methods that connect user input with core file system logic

🚀 Highlights of Implementation
Tree-based directory structure using nested objects
Modular helper methods for each operation
Recursive search implementation
Strong exception handling for invalid input and edge cases
Clean separation between logic and user interaction
Designed entirely in-memory to mimic real file system behavior
